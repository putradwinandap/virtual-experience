# Licensing

Virtual Experience uses a dual-license model because this repository contains both educational written material and software/tooling.

## Written content — CC BY 4.0

Unless a file explicitly says otherwise, the following material is licensed under the **Creative Commons Attribution 4.0 International License (CC BY 4.0)**:

- `experiences/**` — Domain, Area, Topic, and Scenario prose and scenario metadata;
- `docs/**` — project documentation, decisions, planning, reviews, and context;
- root Markdown documentation, including `README.md`, `CONTRIBUTING.md`, `EXPERIENCE_TEMPLATE.md`, and `AGENTS.md`.

The canonical content-license notice is `LICENSE-CONTENT`. The full legal code is published by Creative Commons at https://creativecommons.org/licenses/by/4.0/legalcode.

CC BY 4.0 permits sharing and adaptation, including commercial use, subject to its terms, including attribution. Attribution does not imply endorsement and does not prove that a scenario represents the contributor's first-hand experience.

## Software and tooling — Apache-2.0

Unless a file explicitly says otherwise, software and repository automation are licensed under the **Apache License 2.0**. This includes:

- `scripts/**`;
- `tests/**`;
- `.github/workflows/**`;
- dependency/configuration files whose primary purpose is executing, testing, validating, or automating the software/tooling.

The canonical software license text is `LICENSE-CODE`.

Apache-2.0 was selected instead of MIT because it remains permissive while providing an explicit patent license and patent-termination terms for covered contributions.

## Contributions

Unless a contribution explicitly states otherwise and maintainers agree before incorporation, intentionally submitted contributions are accepted under the license that applies to the repository path/material being changed:

- contributions to written content are contributed under CC BY 4.0;
- contributions to software/tooling are contributed under Apache-2.0.

A single pull request may touch both classes; each part follows the applicable license above.

No CLA or DCO is required at this stage. Contributors must only submit material they have the right to license under the applicable terms.

## Third-party material

This licensing model does not automatically relicense third-party material. A file or asset carrying its own license or notice remains governed by that notice. Contributors must not assume that public availability, attribution, or scenario provenance grants permission to copy third-party text, images, screenshots, trademarks, datasets, or other protected material.

## Provenance is separate from licensing

Virtual Experience scenario provenance (`real`, `adapted`, or `illustrative`) describes how an experience is represented editorially. It is not a copyright ownership claim, license grant, or verification of first-hand authorship.

Git history and optional contributor metadata provide authorship context; neither changes the applicable license.
