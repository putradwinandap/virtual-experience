# Observability

Observability experiences focus on reconstructing what a system actually did from the signals it emits: logs, metrics, traces, and related context.

The goal is not to collect telemetry for its own sake. It is to recognize when missing, inconsistent, or misleading signals distort an investigation and lead teams toward the wrong fix.

- [Distributed Tracing Gaps](distributed-tracing-gaps/) — situations where incomplete trace context hides the path of a request across services.
